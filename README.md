# 📝 Smart Task Manager

**Live Demo:** `https://333blackout.github.io/Smart-Task-Manager/`

### The Power of Core Fundamentals
While modern libraries and frameworks like React, TypeScript, Bootstrap, and Tailwind are incredible tools, relying on them too early can mask a lack of foundational knowledge. 

I built this fully functional Smart Task Manager using **strictly pure HTML5, CSS3, and Vanilla JavaScript** to demonstrate a deep understanding of DOM manipulation, state management, and native browser APIs before abstracting them away with frameworks.

### ✨ Features
* **Dynamic Form Rendering:** Single form logic handles distinct data structures (Lists vs. Text tasks).
* **Data Persistence:** Utilizes the native `localStorage` API to ensure zero data loss on browser refresh.
* **Centralized State Management:** Custom JS logic calculates real-time metrics and updates the UI instantly as data mutates.
* **Native Theme Engine:** Fluid Dark/Light mode toggle built entirely with CSS custom properties.
* **Optimized Event Delegation:** All card interactions are handled via a single parent listener for optimal performance.

### 🛠️ Tech Stack
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Flexbox layout, custom variables, and native UI styling (Zero CSS frameworks used).
* **Vanilla JavaScript (ES6+):** Core application logic, DOM routing, and local storage integration.
